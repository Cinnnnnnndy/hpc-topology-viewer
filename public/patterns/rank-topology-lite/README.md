# 模型分片与训练设备映射 · 简洁版 · Pattern

> 构建产物：`/patterns/rank-topology-lite/pattern.html`
> 中央矩阵本体：[`/patterns/rank-topology-3d/`](../rank-topology-3d/pattern.html)（同源 iframe 嵌入，不是拷贝）
> 契约：同级 `pattern.json`

## 它是什么

`/patterns/rank-topology-3d/` 的**简洁版**——但「简洁」落在外层，不落在矩阵本身。

矩阵、排布、六档通信、preset、ZeRO、物理平铺，这一份**一个字节都不碰**：中央嵌的就是
`/patterns/rank-topology-3d/pattern.html` 本体，同源 iframe，不是另一份拷贝或重新实现。
默认把它定在盘古 ProMoE 预置（`theme=dark`）：`world = TP8 × PP5 × DP100 = 4000` 卡全量渲染，
`EP2` 是同一批 rank 内部的专家路由维度，不额外乘进 rank 总数。它本来的密度就是它的样子——
接受它，不裁剪它。

变的是外层：**环绕式的无限画布**。矩阵钉在画面正中央，是最大、最先看到的主体；点一张卡
下钻之后，那张卡的坐标（矩阵页自己上报的，不是这一层另算的）落成一张卫星卡浮在矩阵四周，
一条细线连回去。下钻越多，画布摊得越大——这是「无限画布」在这里的意思，结构抄的是
[`/patterns/incident-canvas/`](../../incident-canvas/) 同一套「主视图 + 卫星 + 连线」的做法（思路一样，
实现是精简重写，不是整段搬代码）。

外层画布与卫星卡走
[compute-graph-viewer 的抽象图网页 prompt](https://github.com/yinyucheng0601/compute-graph-viewer/blob/main/docs/抽象图网页prompt.md)
（深色极简、无边框灰卡、语义配色只落在训练语义图元上、直角连线）——这份 prompt 管的是外层，
不管矩阵内部怎么画。

## 结构

- **中央矩阵**：一个固定大小的框，里面是 `<iframe src="../rank-topology-3d/pattern.html?embed=1&theme=dark&preset=pangu&...">`。
  它自己的六档通信切换、preset 切换、ZeRO 档位、物理平铺、悬停读数——全部照常可用，这一层什么都没削减。
- **无限画布**：拖动空白处平移，滚轮缩放，右下角工具条（放大 / 缩小 / 回到矩阵 / 看全部）。
- **卫星卡**：在矩阵内点一张卡（触发它自己的 `pto:select` 上报）之后，环绕矩阵四周的八个方位
  浮出一张卡片，写着这张 rank 的真实坐标（`TP · CP · PP · DP`，MoE 预置下还有 `EP`）和一段
  「执行活动」示意色条（前向 → 通信 → 反向 → 通信 → 优化器，长度示意、非实测）。点卡片右上角
  的 `×` 收起。下钻越多，卡片按环状铺满外圈，画布自动缩放去框住新摊开的这一片。

## URL 参数

| 参数 | 取值 | 作用 |
|---|---|---|
| `sel` | 逗号分隔的 rank 列表，如 `12,45,90` | 打开时直接摆好对应的卫星卡；假设默认盘古预置，不给就不预开任何卫星卡 |

## 数据来源与口径

- 卫星卡上的坐标（`TP/CP/PP/DP/EP`）来自矩阵页自己通过 `postMessage` 上报的 `pto:select` 事件里的
  `groups` 字段——是矩阵页当场算出来的真实值，这一层不重新推导。只有 URL 深链（`?sel=`）在页面刚
  打开、还没收到任何真实交互事件时，才用一份本地小算式（假设固定盘古预置）补算坐标，仅用于恢复
  深链，不是运行期的权威来源。
- `world = TP8 × PP5 × DP100 = 4000`：这是从矩阵页实际上报的 `config` 字段里读回来的口径，不是按
  「EP 也是并行维、理应相乘」的直觉猜的——EP 描述的是同一批 rank 内部路由去哪几个专家（All-to-All），
  不是另开一批副本卡，所以不参与 rank 计数。

## 它不回答什么

- **完整的并行度组合切换**——preset / 自定义 tp·cp·pp·dp·ep、ZeRO 档位、物理平铺全部还在矩阵本体
  里，只是这一份把默认值定死在盘古预置。想换配置，直接在中央矩阵内部操作（它自己的控制面板都在）。
- **真实计时**——卫星卡上「执行活动」色块的长度没有真实耗时依据，标注「示意，非实测」；真正的耗时
  估算与传输时间下界仍在矩阵本体的读出面板里。

## 依赖

不是自包含：依赖同一个站点上 `/patterns/rank-topology-3d/pattern.html` 一起发布。离线打开这一份
文件、或者那条路径不存在时，中央矩阵会是一格空白 iframe——这是有意的取舍：打包一份拷贝会让两份
实现分叉，`demo.html` 的修复不会自动传到这一份。
